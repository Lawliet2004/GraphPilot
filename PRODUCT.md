# GraphPilot
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User-specified React, Vite, TypeScript, FastAPI, PostgreSQL and FalkorDB.

## Users
Developers exploring unfamiliar code and investigating dependencies, changes and
CI failures. Administrators manage users, access, jobs and application health.

## Product Purpose
Connect repositories, source symbols and historical evidence in a graph that
supports code investigation and optional AI synthesis. The user confirmed that
repository exploration and source evidence lead the first demo workspace.

## Positioning
Evidence-aware code intelligence with deterministic, scoped graph exploration
that works without paid services or a model provider.

## Operating Context
Local development and a FalkorDB hackathon demonstration, with a deployable web
application and securely allowed server-local/public GitHub/archive ingestion.

## Capabilities and Constraints
The complete requested scope is in docs/REQUIREMENTS.md. All metrics and evidence
must come from real data. Python is the first guaranteed semantic language.
Source must not execute during indexing. Permissions are enforced on the server.
Unknown or incomplete evidence must be disclosed. No automatic code modifications.

## Brand Commitments
GraphPilot. Premium, clean, minimal, professional; light and dark themes.

## Evidence on Hand
No pre-existing content or user data. Small labeled test fixtures will provide
verification. No invented usage metrics, customers, testimonials or AI answers.

## Product Principles
- Make evidence and uncertainty inspectable.
- Keep repository context visible throughout investigation.
- Keep indexing and search useful without an LLM.
- Make every visible control functional or explicitly unavailable.

## Accessibility & Inclusion
Responsive desktop/tablet/mobile web, semantic forms, keyboard navigation,
visible focus, accessible names and reduced-motion support.
