## Direction contract (retrospective)

This formalizes the previously presented direction for future maintenance. It was
not recorded in this format before implementation and is not user approval.

THESIS: Make a code relationship an inspectable path back to its source, with the
repository workspace leading rather than generic metric cards.

OWN-WORLD: Indigo navigation, warm white reading planes, terracotta selections,
quiet typed graph colors, Manrope UI and source-only mono. Standard web controls.

STORY: Choose a repository, find a symbol, trace a typed connection, inspect its
source and distinguish observed evidence from unknown runtime behavior.

FIRST VIEWPORT: At desktop, a 225px left rail and 65px context bar frame the
repository heading, branch/commit, tabs and search/filters. A bounded legible graph
sits beside a 310px evidence panel. Selection adds a direct source action; mobile
stacks the graph and panel with a reachable selected-node summary.

FORM: Architectural Atlas, candidate 6 in the ordered grounded list. Legacy tool
output is retained in `.impeccable/seed-output.txt`; it emitted an 8-hex tool key,
not the current portable 16-hex seed reference. `seed: none (unavailable)`.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
